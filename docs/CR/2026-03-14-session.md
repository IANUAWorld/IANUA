## 4. Decisions de gouvernance prises aujourd'hui

### Separation admin technique / admin politique

En Phase 2, Max reste admin technique (infrastructure, securite, anti-abus) mais n'est plus admin politique. Le cycle de vie des amendements est 100% automatique et communautaire. Seule action politique residuelle : requalification de palier en cas de contestation divergente.

### Cycle de vie automatique des amendements

```
brouillon → proposition → (seuil de soutiens) → deliberation → (vote) → ratifie/rejete
                              ↓ (delai expire)
                            expire
```

Seuils adaptatifs par palier. Transition automatique. Cloture automatique (APScheduler). Aucune intervention humaine requise.

### Audit IA — protocole et declenchement

- Admin technique declenche, communaute ne peut pas
- Prompt identique sans framing Ianua (authenticite)
- Publication explicite par l'admin (non publie par defaut)
- Toute decision (publier OU rejeter) loggee publiquement
- Reponses publiees immuables
- Provider registry extensible
